# Testsigma

> Testsigma is an agentic, GenAI-powered codeless test automation platform. AI "co-workers" work alongside QA teams to author and maintain automated tests in natural language across web, mobile, desktop, API, and packaged apps (Salesforce, SAP). A REST API drives projects, environments, test plans, and remote execution for CI/CD.

Note: Testsigma serves a large verbatim marketing dump at https://testsigma.com/llms.txt (self-titled "llms-full.txt", ~2.2MB). This file is a concise, curated index generated by API Evangelist from the catalog and public docs.
